================================================================================
train_risk_model — Step-level risk scoring with sampled-prefix training
================================================================================

PURPOSE
-------
Trains and evaluates 7 models for predicting task failure probability at
each step of an agent trajectory. Addresses class imbalance via:
  1. Sampled-prefix training  — sample a few prefixes per task per fold
  2. Task-level class weights — weights from task counts, not step counts

See codes/reembed_qwen/training_process.md for full design rationale.


MODELS
------
  Logistic_L2         sigmoid(wx+b) + L2 penalty; C selected by val AUROC
  Ridge               wx+b clipped to [0,1]; alpha selected by val AUROC
  RF                  Random Forest; n_estimators selected by val AUROC
  Calibrated_RF       RF fitted on 80% of train + isotonic calibration on val 20%
  ElasticNet          wx+b clipped + L1+L2; alpha/l1_ratio selected by val AUROC
  LightGBM            Gradient-boosted trees; n_rounds by early stopping on val
  Logistic_ElasticNet sigmoid(wx+b) + L1+L2; C/l1_ratio selected by val AUROC


CHECKPOINT / PARAM SELECTION (val split)
-----------------------------------------
Every model uses an 80/20 split of the outer training fold:
  - 80% inner_train : model fitting
  - 20% val         : checkpoint / hyperparameter selection (criterion: AUROC,
                       except LightGBM which uses log-loss for early stopping)

After selection the winning configuration is re-fitted on the FULL outer
training fold before evaluating on the test fold.

  Model               Search space
  ------------------- ----------------------------------------------------------
  Logistic_L2         C in {0.01, 0.1, 1.0, 10.0}
  Ridge               alpha in {0.01, 0.1, 1.0, 10.0, 100.0}
  RF                  n_estimators in {50, 100, 150, 200, 300} (warm_start)
  Calibrated_RF       val used for isotonic calibration (no param search)
  ElasticNet          alpha in {0.001,0.01,0.1,1.0} x l1_ratio in {0.1..0.9}
  LightGBM            up to 500 rounds, early_stopping patience=30
  Logistic_ElasticNet C in {0.01,0.1,1.0,10.0} x l1_ratio in {0.1..0.9}


SAMPLING STRATEGIES (--sampling)
---------------------------------
  uniform   sample --max_prefix prefixes per task uniformly at random
  balanced  sample one prefix from each of early / middle / late thirds
  fixed     keep at most --max_prefix prefixes per task (same as uniform)

Default: balanced, max_prefix=5


CLASS WEIGHTS
-------------
Computed per outer-train fold from task counts:
  w_failure = (N_f + N_s) / (2 * N_f)
  w_success = (N_f + N_s) / (2 * N_s)
Each sampled prefix inherits its task's weight.


EVALUATION
----------
  5-fold stratified CV at the task level (all steps of a task in same fold)
  Test set: ALL steps of held-out tasks (no sampling at test time)

Metrics per fold:
  AUROC   primary ranking metric (robust to imbalance)
  AUPRC   area under precision-recall curve (informative when success is rare)
  Brier   mean squared error of probabilities
  ECE     expected calibration error

Feature sets evaluated separately:
  macro_only   22 trajectory features
  uq_only      33 HLVM UQ features
  all          22 + 33 + 3 reasoning = 58 features


INPUT
-----
  {source}/{uq_dir}/feature_matrix.csv
  (built by codes/build_feature_matrix/build_feature_matrix.py)


OUTPUT
------
  {source}/{uq_dir}/risk_model_results/{run_tag}/
    cv_predictions_{fs}.csv   per-step test predictions for all models (used by
                               plot_prek_auroc.py); fs in {macro_only,uq_only,all}
    cv_results.json            AUROC + AUPRC + Brier + ECE per model x fs x fold
    summary_table.csv          mean +/- std across 5 folds
    feature_importance.json    RF + LightGBM importances, LR/ElasticNet coefs
    prek_auroc_{fs}.png        per-step-k AUROC curves (generated by plot script)

  WARNING: rerunning with the same --sampling / --max_prefix overwrites all
  files in the existing run folder. Back up the folder first if needed.


PLOTTING PER-k AUROC
--------------------
  python codes/train_risk_model/plot_prek_auroc.py --source webarena/claude
  # auto-picks most recently modified run folder; or specify:
  python codes/train_risk_model/plot_prek_auroc.py \
      --source webarena/claude --run_tag sampling=balanced_prefix=5


DEPENDENCIES
------------
  pip install scikit-learn lightgbm pandas numpy matplotlib


USAGE
-----
All commands from results_total/.

  # WebArena — Claude (balanced sampling, 5 prefixes)
  python codes/train_risk_model/train_risk_model.py --source webarena/claude

  # WebArena — GPT
  python codes/train_risk_model/train_risk_model.py --source webarena/gpt_5_2

  # WebArena — Qwen (heavily imbalanced, try more prefixes)
  python codes/train_risk_model/train_risk_model.py --source webarena/qwen30b --max_prefix 8

  # Mind2Web — Qwen
  python codes/train_risk_model/train_risk_model.py --source mind2web/qwen30b

  # Use original MiniLM UQ results
  python codes/train_risk_model/train_risk_model.py \
      --source webarena/claude --uq_dir uq_analysis_change

  # Uniform sampling with 3 prefixes
  python codes/train_risk_model/train_risk_model.py \
      --source webarena/claude --sampling uniform --max_prefix 3


KEY PARAMETERS (edit at top of script to change defaults)
----------------------------------------------------------
  RF_PARAMS    max_depth=8, min_samples_leaf=5
               n_estimators selected by val AUROC from {50,100,150,200,300}
  LGB_PARAMS   max_depth=4, learning_rate=0.05
               n_estimators selected by early stopping (patience=30, max=500)
  ElasticNet val grid: alpha in [0.001,0.01,0.1,1.0],
                       l1_ratio in [0.1,0.3,0.5,0.7,0.9]
  LogisticElasticNet val grid: C in [0.01,0.1,1.0,10.0],
                               l1_ratio in [0.1,0.3,0.5,0.7,0.9]


NOTES
-----
- All models use an 80/20 val split inside each outer training fold for
  checkpoint / hyperparameter selection; the winner is then refit on the
  full outer training fold before evaluation on the test fold.
- Calibrated_RF is the exception: its val 20% is used for isotonic calibration
  rather than param selection, and it does not refit on the full fold.
- NaN features are imputed with training-fold medians before fitting.
- AUPRC baseline = n_failure_steps / n_total_steps (random classifier).
  For mind2web/qwen30b this is ~0.07 — values above this are meaningful.
- ECE is corrected via post-hoc calibration (isotonic regression for RF models,
  temperature scaling for linear models) fitted on an unweighted calibration set.
